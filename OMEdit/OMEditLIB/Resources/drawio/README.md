# draw.io viewer

`viewer-static.min.js` is the draw.io (diagrams.net) viewer, version 31.5.3, from
https://github.com/jgraph/drawio/blob/v31.5.3/src/main/webapp/js/viewer-static.min.js
under the Apache License 2.0 (`LICENSE`).

The Class Diagram view (`Modeling/ClassDiagramWidget.cpp`) uses it to show the
draw.io diagrams of `getClassDiagram` offline. To update it, replace the file with
the one of a newer release tag and change the version here.
