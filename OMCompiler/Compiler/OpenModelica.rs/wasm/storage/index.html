Install a library

Installs a Modelica package that is not in the package index, from a .mo file, a .zip file or a folder. An installed library is read-only in the clients. To change a library, open it in OMEdit with File > Open Model/Library File(s) instead.

ContentsSizeChanged

The OpenModelica clients keep installed libraries, the package index and a parse cache here, so they load without a download in the next session. A client that is open keeps what it had until it is reloaded; the space comes back once no client uses it.
