# User's Guide

OpenModelica User's Guide using Sphinx (Python Documentation Generator).

The guide is generated by *running* OpenModelica: omc executes the examples in
the text and the guide shows their real output. It therefore needs a complete,
installed OpenModelica to document, and is built after that install rather than
as part of it.

## Dependencies

Getting all dependencies right is a nightmare. Just use the dev container
`build-deps` from
[.devcontainer/README.md](./../../.devcontainer/README.md) and set
`GITHUB_AUTH`.

- an installed OpenModelica (omc and OMSimulator)
- Inkscape > v1.0
- [Sphinx](http://sphinx-doc.org/)
- pandoc
- gnuplot
- Python3 and packages from [source/requirements.txt](./source/requirements.txt)

   ```bash
   pip install --upgrade -r source/requirements.txt
   ```

Sphinx and that Python environment have to be the same one: `conf.py`, the
`sphinxcontribopenmodelica` extension and `resolve-crossref.py` all import from
`requirements.txt`. Configuring prints which `sphinx-build` and which interpreter
were picked, so a mismatch is visible before the build starts.

### GITHUB_AUTH (optional)

Create a read-only personal access token (API token) on GitHub.com and define an
environment variable `GITHUB_AUTH` with your secret API token.

```bash
export GITHUB_AUTH=XXXXXXXXXXX
```

This is used to read the release notes from
<https://github.com/OpenModelica/OpenModelica> with the PyGithub package. Without
it they are read anonymously, which works but is rate limited to 60 requests an
hour.

## Build instructions

As part of an OpenModelica build, after installing it:

```bash
cmake -S . -B build_cmake -DOM_ENABLE_DOCS=ON
cmake --build build_cmake
cmake --install build_cmake
cmake --build build_cmake --target usersguide
```

Or on its own, against an OpenModelica installed anywhere:

```bash
cmake -S doc/UsersGuide -B build-doc -DOM_USERSGUIDE_OMHOME=/usr/local
cmake --build build-doc
```

Nothing is generated into the source tree; the guide ends up in
`<build dir>/doc/UsersGuide/build/html` (or `build-doc/build/html`).

The other targets are `usersguide-pdf`, which needs a LaTeX installation with
`latexmk` and writes `build/latex/OpenModelicaUsersGuide.pdf`, and
`usersguide-releases`, which re-reads the release notes appendix from GitHub.
Both the HTML and the PDF are installed by the `doc` component if they have been
built.
